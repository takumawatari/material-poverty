# Global assessment of material poverty and inequality

This repository contains data supporting the study “Global assessment of material poverty and inequality”.

Material stock data: [MaterialCities](https://doi.org/10.5281/zenodo.22306604).

## Citation
If you find this repository useful for your work, please cite the associated paper:
> Watari, T. et al. Global assessment of material poverty and inequality

If you use the underlying material stock data, please cite the MaterialCities paper:
> Fishman, T. et al. MaterialCities dataset: mapping buildings' material stocks and floor area of the world's 1.8 million settlements by structures and functions
